# Pomodoro

シンプルなポモドーロタイマー（PWA）。サーバー不要の静的ファイルのみで動作し、データはすべて端末内（localStorage）に保存されます。

## 機能

- 作業／休憩時間を任意に設定（開始時刻との差分計算のため、バックグラウンドでもずれません）
- 終了時にサイレント通知（音・振動なし）
- 4ポモドーロごとに「金のポモドーロ」を獲得（1日単位）
- カレンダーで日々の実績と完了時刻を確認
- CSVエクスポート／インポート（BOM付きUTF-8）
  - 本日分が重複 → 端末のデータを優先
  - 昨日以前が重複 → CSVの内容で上書き
- カレンダー画像（PNG）の保存と、SNS投稿用テキストのコピー
- オフライン動作（Service Worker）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | デザイン |
| `app.js` | アプリのロジック |
| `manifest.json` | PWA定義 |
| `sw.js` | オフライン用キャッシュ |
| `icons/` | アイコン |

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作成します（例: `pomodoro`、Public）。
2. このフォルダの中身（`index.html` など。フォルダ自体ではありません）をリポジトリ直下にアップロードします。
   - Webの場合: 「Add file」→「Upload files」にドラッグ＆ドロップし、「Commit changes」を押します。
   - `icons` フォルダも含めてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を `Deploy from a branch` にします。
5. Branch を `main`、フォルダを `/ (root)` にして **Save** を押します。
6. 1〜2分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

> 自分専用にしたい場合は、推測されにくいリポジトリ名にしてください（Publicリポジトリのページは誰でもアクセスできます）。

## iPhone / iPad にインストールする

1. **Safari** で公開URLを開きます（他のブラウザでは不可）。
2. 共有ボタン → **「ホーム画面に追加」** を選びます。
3. ホーム画面に追加されたアイコンから起動します。
4. 初回の「開始」ボタンで通知の許可を求められたら、許可します。

- 通知はiOS 16.4以降で、**ホーム画面から起動したアプリのみ**利用できます。
- 初回のみネット接続が必要です。以降はオフラインでも動作します。
- 音を完全に消したい場合は、端末のマナーモードや通知設定も確認してください。

## PC（Chrome / Edge）にインストールする

アドレスバー右側のインストールアイコンから追加できます。

## 更新するとき

1. ファイルを修正して、リポジトリに上書きアップロードします。
2. `sw.js` 1行目の `CACHE` の番号を上げます（例: `pomodoro-v1` → `pomodoro-v2`）。
3. アプリを開き直すと、新しい版に切り替わります（反映されない場合は一度アプリを終了して再度開いてください）。

## データのバックアップ

記録は端末のブラウザ内にのみ保存されます。機種変更やデータ消去に備えて、「共有・CSV」タブからCSVを定期的にエクスポートしてください。

## ローカルで試す（任意）

```
npx serve .
```

`http://localhost:3000` で動作確認できます（Service Workerは `localhost` またはHTTPSでのみ動作します）。
